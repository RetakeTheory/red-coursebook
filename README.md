# 红课题本

红课题本是可离线使用的桌面练习工具。2026 秋季版内置两门课的题干、选项和答案，打开程序后可在页面顶部切换题库。

| 题库 | 单选 | 多选 | 范围 |
| --- | ---: | ---: | --- |
| 习概《习近平新时代中国特色社会主义思想概论》 | 70 | 30 | 全册 100 题 |
| 毛概《毛泽东思想和中国特色社会主义理论体系概论》 | 197 | 143 | 导论和第一至第八章，共 340 题 |

## 下载

前往 [Releases](https://github.com/RetakeTheory/red-coursebook/releases) 下载对应系统的文件。

| 系统 | 使用方法 |
| --- | --- |
| Windows x64 | 双击 `RedCoursebook-Windows-x64.exe`。界面使用系统的 Microsoft Edge WebView2 运行时。 |
| macOS 14 或更新版本 | 解压 `RedCoursebook-macOS-universal.zip`，打开「红课题本.app」。同一个包支持 Apple Silicon 和 Intel。 |

## 作答

- **练习模式**可选全部、单选或多选。单选点选后立即显示答案，多选点「确认答案」后判题。在「练习设置」点「重置练习进度」并确认，即可清零当前课程全部章节的练习作答、位置和用时，保留错题本、测试记录和另一门课的进度。
- 毛概可在「练习章节」选择全册或单章，再选择题型。题目卡显示所属章节，答题卡按章排列。第一章原单选区第 17 题给出的答案是 A、C、E，题本按多选判分，并保留原题号。
- **全册随机测试**适用于两门课程。每次从全册随机抽取 14 道单选和 6 道多选，题目不重复，每题 3 分，满分 60 分。
- **毛概全做 340 题**按导论至第八章的顺序覆盖全册，包括 197 道单选和 143 道多选，满分 1020 分。毛概的两种试卷分别保存，点「测试设置」可以切换，继续时会回到上次的题目。
- 测试交卷后可查看成绩和逐题答案。每题 3 分，多选须全部选对，所有题都作答后即可交卷。
- **错题本**收录练习和已交卷测试中的错题。重练答对后移出。
- 开始作答前可选择**打乱选项顺序**。屏幕上的字母会随选项重新排列，本轮返回题目或重开程序时沿用相同顺序。
- 右侧答题卡可以跳题，同时显示答题进度与用时。测试从开卷计时至交卷。练习记录、未完成测试和显示偏好保存在当前设备。
- 两门课程分别保存练习位置、答题、错题和测试。打开新版会接续旧版的习概、毛概记录。

## 构建

使用 Node.js 22 或更新版本、npm 和 Python 3。从项目根目录运行下列命令。准备脚本会校验指定版本的框架下载文件，也可传入已有的官方压缩包路径。

```sh
npm ci
python prepare_runtime.py
npm test
npm run build
```

Windows 可执行文件位于 `build/dist/RedCoursebook/`。在 macOS 上可用以下命令生成通用应用包，命令需要 Pillow 和系统的 `codesign`。在 Windows 上打包 Mac 应用时，另需将 `rcodesign.exe` 加入 PATH 或放在 `build/` 内。

```sh
python -m pip install Pillow
python package_mac.py
```

习概结构化题库位于 `site/bank.json`，可用 `python import_bank.py "习概题库.docx"` 重新生成。毛概结构化题库位于 `site/mao.json`，可将原始 Word 97–2003 文档另存为 DOCX，再运行 `python import_mao.py "毛概题库.docx"`。毛概题目标识保留了原章、原题型区和原题号。
